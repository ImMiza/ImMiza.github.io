    Variables

    Repères

    Variables globales déclarées dans game/script.rpy (lignes 219-258). Les variables propres à un arc (arc2_*, arc3_*…) sont détaillées dans les pages d’arc et dans Choix. Le détail ligne par ligne des effets de chaque option est dans Choix. Le calcul de l’embranchement a sa propre page : Calcul de l’embranchement.

    Vue d’ensemble

    Section intitulée « Vue d’ensemble »

    Toutes ces variables partent de leur valeur par défaut au début d’une partie. Le joueur ne les voit jamais à l’écran.
